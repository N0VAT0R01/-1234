# Спето в КнАГУ

Статический сайт для GitHub Pages. Никаких сборщиков, npm или серверной части не требуется.

## Как редактировать песни

### 1. Название и исполнитель

Откройте `songs.js` и измените только две строки нужной песни:

```js
{ title: 'Новое название', artist: 'Новый исполнитель', lyricsFile: '01.txt' }
```

### 2. Текст песни

Откройте соответствующий файл в папке `lyrics/`, например:

```text
lyrics/01.txt
```

Вставляйте текст прямо как обычный текст. Можно использовать:

- обычные переносы строк;
- пустые строки между куплетами;
- кавычки;
- апострофы;
- тире;
- скобки;
- символы `&`, `<`, `>` и т. п.

**Не нужно** добавлять кавычки вокруг всего текста и не нужно писать `\\n`.

### 3. Важное правило GitHub

При изменении песни загружайте на GitHub **оба изменённых файла**: `songs.js` и/или соответствующий TXT-файл из `lyrics/`.

Не переименовывайте TXT-файл, если не изменили `lyricsFile` для этой песни.

## GitHub Pages

В репозитории откройте `Settings → Pages` и выберите публикацию из нужной ветки, обычно `main`, папка `/ (root)`.

После изменения файлов дождитесь завершения GitHub Pages. Если браузер показывает старую версию, используйте Ctrl+F5.

## Локальный просмотр

Поскольку тексты загружаются из TXT-файлов через `fetch()`, для локальной проверки нужно запускать простой HTTP-сервер, а не открывать `index.html` двойным кликом.

Например, в папке проекта:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.
